## О проекте

**DiscordCloner** — это консольный CLI-инструмент, который переносит структуру одного Discord-сервера на другой: роли со всеми настройками, каналы и категории с правами доступа, эмодзи, стикеры, а также название, аватарку и баннер сервера.

Инструмент построен на надёжной обработке ошибок Discord API — при отказе создания канала (например, из-за недопустимых символов в названии или устаревшего голосового региона) выполняется автоматический разумный откат, а не остановка всего процесса.

## Возможности

- 🎭 **Полное клонирование ролей** — имена, цвета, разрешения, позиции в иерархии
- 🗂 **Клонирование каналов и категорий** — с правами доступа и сохранением структуры
- 🛡 **Устойчивое создание каналов** — при `400 Bad Request` от Discord API выполняется повтор с нормализованным названием, а при необходимости — без эмодзи и спецсимволов
- 🎙 **Проверка голосовых регионов** — `rtc_region` каналов сверяется с актуальным списком регионов Discord; недопустимые или устаревшие значения просто отбрасываются вместо падения запроса
- 😀 **Клонирование эмодзи и стикеров** — с учётом буст-лимитов целевого сервера
- 🖼 **Копирование оформления сервера** — название, аватарка, баннер
- ⚙️ **Гибкие режимы работы**:
  - Полное клонирование (роли + каналы + настройки)
  - Только эмодзи и стикеры
  - Только роли (с разрешениями и позициями или без)
- 💾 **Снепшоты сервера в локальной SQLite-базе** — полная структура сервера (роли, каналы, права, эмодзи, стикеры, оформление) сохраняется локально и может быть повторно склонирована без нового сканирования оригинала
- 🔄 **Бэкап и откат** — перед клонированием можно сохранить текущее состояние целевого сервера и восстановить его позже, если что-то пошло не так
- 🪵 **Понятный лог ошибок** — в отчёт попадает реальная причина отказа от Discord API, а не общий код ошибки
- 🌍 **Русский и английский интерфейс** — выбор языка на первом экране, до ввода токена
- 🔐 **Зашифрованное сохранение сессии** — токен и язык можно сохранить локально (AES-256-GCM + scrypt, разблокировка по вашему мастер-паролю); при повторном запуске — автоматический вход с отображением ника аккаунта
- 📋 **Главное меню после входа** — клонирование, клонирование из сохранённых снепшотов, история операций, смена аккаунта или удаление сохранённых данных (с двойным подтверждением и опциональным бэкапом)
- 🎨 **Продуманное меню** — иконки, описания под пунктами, группировка и подсветка опасных действий; синие разделители и "хлебные крошки" показывают, где вы находитесь
- ✨ **Анимированный запуск** — красивое появление логотипа и авторства при старте; можно отключить в меню "Настройки"
- 📊 **Прогресс-бар вместо стены логов** — при клонировании ролей/каналов/эмодзи/стикеров
- 📄 **Сохранение отчёта** — итоги каждого клонирования пишутся в лог-файл
- 🪟 **Портативный `.exe` для Windows** — сборка в единый исполняемый файл со своей иконкой, без установки Node.js на целевой машине

## Установка

```bash
git clone https://github.com/ownersystem/DiscordCloner.git
cd DiscordCloner
npm install
```

## Запуск

Режим разработки (без сборки):

```bash
npm run dev
```

Или сборка и запуск скомпилированной версии:

```bash
npm run build
npm start
```

## Использование

1. При первом запуске выберите язык интерфейса (🇷🇺 Русский / 🇬🇧 English).
2. Введите Discord-токен.
3. Укажите **ID исходного сервера** (с которого клонировать) и **ID целевого сервера** (куда клонировать).
4. Выберите режим клонирования и следуйте подсказкам на экране.

## Снепшоты и бэкапы

При клонировании сервера система предлагает два независимых сохранения — оба хранятся локально в файле `data/snapshots.sqlite` (настоящая SQLite-база):

- **Снепшот исходного сервера** — полная структура (роли, каналы, права доступа, эмодзи и стикеры вместе с картинками, оформление сервера) сохраняется локально. Такой снепшот можно повторно склонировать на любой другой сервер через пункт меню **«📦 Клонировать из сохранённых»** — без повторного обращения к оригинальному серверу.
- **Бэкап целевого сервера** — перед тем как текущие каналы и роли на целевом сервере будут удалены, можно сохранить их состояние «на всякий случай». Если после клонирования что-то пошло не так, этот бэкап отображается в том же списке **«Клонировать из сохранённых»** — восстановление сводится к выбору бэкапа и повторному клонированию его на тот же сервер.

Оба варианта — это обычные `y/n`-вопросы в процессе клонирования, сохранение всегда по желанию.

## Сборка Windows-версии (.exe)

Проект можно собрать в единственный самодостаточный `DiscordCloner.exe` — без установки Node.js на машине, где будет запускаться готовый файл, и без сторонних файлов рядом.

```bash
npm install
npm run build:exe
```

Готовый файл появится в `dist-exe/DiscordCloner.exe`. Команда делает всё сама: компилирует TypeScript, собирает весь код в один JS-бандл через `esbuild` (это важно для стабильности — упаковка `node_modules` напрямую в `pkg` может повредить внутренний загрузчик), затем упаковывает бандл вместе с WASM-модулем SQLite (как бинарный ассет, а не как часть кода) в один исполняемый файл через `pkg`.

Файлы сессии (`data/session.enc.json`) и база снепшотов (`data/snapshots.sqlite`) создаются рядом с `.exe` при первом запуске.

**Известное ограничение:** кастомная иконка (`discordcloner.ico`) сейчас не встраивается в `.exe` автоматически — инструменты для редактирования ресурсов Windows-бинарников (проверено несколько) в связке с этой версией `pkg` повреждают файл. Функциональность важнее иконки, поэтому пока собирается рабочий `.exe` со стандартной иконкой Node.js.

## Требования

- **Node.js** 18 или новее (только для сборки — готовый `.exe` Node.js не требует)
- Токен аккаунта или бота с необходимыми правами на обоих серверах

---

## Предупреждение

> ⚠️ **Полное клонирование удаляет все существующие каналы и роли на целевом сервере.** Это действие необратимо. Используйте инструмент только на серверах, где у вас есть право вносить такие изменения.
